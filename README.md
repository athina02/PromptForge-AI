# 🐸 PromptForge AI

> **Build Better Prompts.**

PromptForge AI is a modern Progressive Web App (PWA) that helps users discover, search, save, and instantly copy high-quality AI prompts. It is designed with a premium glassmorphism interface and works both online and offline.

## 🌐 Live Demo

https://athina02.github.io/PromptForge-AI/

## ✨ Features

- 🔥 25 Production-ready AI prompts
- 💼 Business prompts
- 📚 Study prompts
- 💻 Coding prompts
- 📱 Social Media prompts
- 🏋️ Fitness prompts
- 🔍 Live Search
- ❤️ Favorites (Local Storage)

- 📤 Native Share Support

## 🚀 Installation

### Web

Open the live website:

https://athina02.github.io/PromptForge-AI/

### Install as an App

1. Open PromptForge AI in Chrome.
2. Tap **Add to Home Screen**.
3. Enjoy the full app experience with offline support.
